# Monster Buster

原創橫向卷軸動作＋抓寵網頁遊戲。使用 Canvas 製作，手機與電腦皆可遊玩。

## v0.1

- 橫向卷軸、平台跳躍、鏡頭跟隨
- 獨立遠景／中景／前景素材，以 0.08／0.28／0.72 倍速做三層視差捲動
- 普通／蓄力射擊、空中控制、衝刺
- 四種屬性魔獸、生命值削弱與機率捕捉
- 捕獲魔獸永久保存於瀏覽器本機圖鑑，並自動支援作戰
- 關底核心守衛與原創 ImageGen 角色、魔獸、場景素材
- 不包含 EatJoy 的任何工作、排班、廚務、帳號、Firebase、LINE 或 n8n 系統

## 操作

- `A` / `D`：移動
- `Space`：跳躍
- 按住 `J`：蓄力，放開射擊
- `K`：衝刺
- `L`：捕捉最近且生命低於 35% 的魔獸

執行 `npm run dev` 後開啟 `http://localhost:4173`。

本作僅採用經典橫向動作射擊類型的通用玩法，不使用《洛克人》角色、名稱、美術、音樂或其他受保護素材。
